## 说明文字

页面展示训练与推理任务提交前的调度策略模板、资源规格和节点匹配结果。当前选择「性能优先」模板，页面同时给出 CPU 核数、内存、GPU 数量、调度优先级、节点类型和单任务时限，并在提交前给出资源校验结论。

## 红框描述列表

1. 框选顶部标题「异构算力智能调度中心」及副标题，证明页面属于异构算力调度功能。
2. 框选「调度策略模板」卡片，覆盖「性能优先、成本优先、快速启动、GPU 专用」四个可选模板及当前选择状态。
3. 框选「提交前资源规格」卡片，覆盖 CPU 核数 `32 vCPU`、内存 `128 GiB`、GPU 数量 `4 × A800`、调度优先级 `P1 / 高`、节点类型 `GPU-A800`。
4. 框选「提交前校验通过」状态条，证明策略参数与资源配额在提交前完成校验。
5. 框选底部「调度参数与匹配规则」表的表头和「性能优先」行，覆盖模板、CPU、内存、GPU 数量、优先级、节点类型及「匹配」状态。
