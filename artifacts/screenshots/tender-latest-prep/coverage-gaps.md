## 现有截图覆盖不足

1. **可观测性数据采集第 1 项**：有清洗 / 去重结果，但没有独立的缺失值处理配置、异常检测记录或多源输入对比。
2. **可观测性数据采集第 2 项**：有质量、映射、标准化和流水线概览，但没有明确展示按数据类型、质量规则、目标格式配置处理流程的界面。
3. **多源数据质量第 1 项**：有质量状态，但没有明确展示正则 / SQL / Python 自定义规则、异常记录和通过率统计。
4. **多源数据质量第 2 项**：有冲突、血缘和图谱，但没有明确展示时间戳 / IP / 端口 / 实体 ID 关联条件配置，也没有模糊或语义匹配配置。
5. **多源数据质量第 3 项**：有质量和血缘结果，但没有完整的缺失 / 错误 / 重复 / AI 标签均衡指标，以及根因节点下钻。

## 严格交付需要补充的三类截图

以下每类至少补 1 张来自正式前端页面的干净截图，再由接替模型按说明绘制红框：

1. **清洗配置 + 异常统计**：同时可见缺失值处理、去重、异常检测、多源输入对比，以及异常数量 / 通过率等统计。
2. **跨源关联条件 + 关联图谱**：同时可见时间戳、IP、端口、实体 ID 等关联条件，模糊 / 语义匹配方式，以及结果关联图谱。
3. **质量指标明细 + 根因节点下钻**：同时可见缺失、错误、重复、AI 标签均衡等指标，并能从质量异常或风险结果定位到根因节点。

## 当前限制与防误用规则

当前仓库前端的实际结构化页面仅提供汇总质量规则表、冲突候选值、血缘和资产图等面板，没有上述三类独立配置 / 统计 / 根因下钻面板。因此本次不使用临时 DOM 拼接页面或非真实数据来冒充正常前端功能，也不把已有概览截图标成“全细项已覆盖”。

补图完成前，投标材料应沿用“页面功能概览”口径；补图完成后，应为每张新增图片建立同名 `.md`，写明条款映射、数据口径、红框目标和可见边界。
