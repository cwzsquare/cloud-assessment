## 说明文字

页面展示完整性、唯一性、名称有效性、类型一致性、引用完整性、时间连续性和血缘完整性等质量规则，并以 PASS、FAIL、UNKNOWN 状态呈现结果；同屏给出数据血缘统计和资产关系图。

## 红框描述列表

1. 框选「数据质量规则」标题及表头「规则、维度、状态」。
2. 框选 `DQ-COMPLETE`、`DQ-UNIQUE`、`DQ-NAME`、`DQ-TYPES` 四行，覆盖完整性、唯一性、名称和类型校验状态。
3. 框选 `DQ-REFERENCE` 的 `FAIL`、`DQ-TIME` 的 `UNKNOWN` 和 `DQ-LINEAGE` 的 `PASS`，体现异常、证据不足和通过状态并存。
4. 框选「数据血缘」统计卡中的节点数、关系数和可追溯对象数。
5. 框选「资产关系图」标题及可见资源节点，作为血缘 / 关系结果的辅助展示。

## 标注边界

不要将资产关系图中的每个节点分别画成大量小框；可用一个覆盖图面和控件的框表示图谱区域，再用质量表逐项标注状态。
## 覆盖边界

本图证明内置质量规则的状态结果可见；不展示正则 / SQL / Python 自定义规则、异常记录或通过率统计配置，因此不能作为多源质量第 1 项的完整证明。
